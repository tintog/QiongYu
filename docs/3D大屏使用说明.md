# 3D气象演示大屏

2026-10-09，新入口位于顶部导航“3D大屏”。沿用现有登录、账号权限及全局批次；管理员在顶部切换批次后，大屏随系统重新加载。启动方式仍为项目的 start.bat。

进入大屏后使用独立布局：顶部仅保留56px工具栏，包含返回工作台、时钟、标题、预报批次、账号及全屏／退出操作。隐藏工作台的多模块导航、全局说明栏和页脚，三维场景自动填满剩余窗口；全屏时保留独立顶栏。左上角信息卡显示起报与有效时间，避免重复大标题。已按1920×1080与1366×768验收，不产生页面横向或纵向滚动。左侧采用预报／区域／图层页签，默认显示预报；区域支持名称搜索。右侧默认收为全国场紧凑摘要，点击位置自动展开该格点的单点曲线，可切换全国／单点／风险并关闭或重新展开。全国统计与单点统计明确区分。底部集中图标工具栏，右上角独立指北针；巡航工具打开设置弹层，可调整每站停留时间、启停巡航或进入山地视角。时间轴及版权状态区收为92px，面板与工具避免相互遮挡。

## 已实现

- Cesium三维地球、Sentinel-2 2024卫星影像、ArcGIS Terrain3D真实高程、省级边界与省级中心标注。提供本地Natural Earth离线底图回退，无需填写地图密钥。
- 现有9类确定性气象要素；降水支持6小时、24小时和起报至当前累计。
- 同起报集合降水概率，支持1、5、10、20、50 mm/6h阈值；没有配套集合时显示提示，不跨批次补数据。
- 基于接口可用时效的时间轴、逐帧切换、循环播放、播放速度选择；不足24小时自动切回6小时累计。
- 区域定位、地图点选、确定性单点曲线、进入既有单点详情。
- 气象场透明度与显示开关、平滑显示开关、在线／离线底图切换、真实高程开关、省界与地名开关、左右面板收放、指北针、视角复位、全屏。新增倾斜、俯视、四川龙门山地形展示视角；山地展示会关闭气象层以便观察，可手动重新打开。
- 中国全景与部分省级中心的相机巡航，可暂停；鼠标在场景按下时停止巡航并交还控制。
- 整批次风险峰值摘要、当前降水场区域排行、最大与平均值。

## 数据与显示口径

起报时间按UTC标注，图层有效时间和屏幕当前时间使用北京时间。时效请求期间旧气象场隐藏，数据加载完成后显示新的有效时间，失败时显示错误且停止播放。

风险摘要是整个批次的24小时滑动累计峰值，不是当前帧预警。区域排行是原接口的省级中心邻域最大值，不是行政区域全覆盖统计。概率模式下的单点曲线仍是所选确定性要素，界面明确标注。

格点场按格点中心、经纬度和北向上生成纹理，低于0.1 mm的降水格点透明。默认启用4倍分辨率的双线性数值插值与连续色彩显示，微量降水透明度较低，默认图层整体透明度为55%；可以关闭平滑以查看原始格点。插值不跨缺测格点，不改变接口统计、评分或原始数据，也不代表提高预报精度。图例显示当前场的最小与最大色标范围；切换时效后色标可能变化，数值对比以统计及曲线为准。风速展示标量场，未实现粒子风动画。

在线底图为Sentinel-2 2024无云影像合成，并非实时卫星影像；地形采用ArcGIS Terrain3D高程瓦片，点击显示场景拾取高度。在线来源连接失败自动回退本地底图／椭球，并明确显示当前状态；瓦片细化期间显示加载提示。未加载城市建筑、倾斜摄影等3D Tiles模型，不能将卫星影像＋高程称为城市实景三维模型。Cesium、EOX及高程来源的版权信息保留。

影像来源与许可：[EOxCloudless](https://cloudless.eox.at/documentation/license)，2024影像按CC BY-NC-SA 4.0用于非商业演示，商业部署需使用相应授权数据。高程接口参见[Cesium官方文档](https://cesium.com/learn/cesiumjs/ref-doc/ArcGISTiledElevationTerrainProvider.html)。

## 安装与构建

新增cesium依赖，首次部署新版本需在frontend执行npm install（或重新运行install.bat）。常规构建为npm run build，完整部署frontend/dist目录，必须保留dist/cesium下的Workers、Assets、Widgets、ThirdParty目录。三维组件按需加载，首次进入时才加载其代码。

开发环境由vite.config.js提供本地Cesium资源；生产环境由构建插件复制资源。默认使用站点根路径/cesium/，子路径部署需同步调整CESIUM_BASE_URL和本地底图路径。

本机系统Node 22.22.2曾在大型包构建阶段异常退出，使用Node 24.19.0完成构建。若出现同样退出，应使用Node 24并保证可用内存；不影响已构建页面的运行。

## 验证

- weather-texture.mjs检查南北方向、格点边界、缺测与无雨透明度。
- 原有data-workflow.mjs与point-linkage.mjs继续验证通过。
- screen-browser.cjs以真实本地接口验证WebGL加载、下一帧、气温、区域单点、集合概率、巡航、播放、全屏和卸载后重新进入，并检查页面错误及Cesium资源错误。
- 浏览器测试使用独立端口5175及Edge无头模式。测试账号可用SCREEN_USER、SCREEN_PASSWORD环境变量配置，生产不修改密码或账号。

首选展示尺寸为1920×1080；建议桌面宽度至少1280像素。右侧单点曲线位于摘要面板下方，可滚动查看。

## 扩展范围

当前版本不含3D Tiles实景模型、量测绘制、卷帘、风粒子和高空体渲染。加入这些功能时应明确数据源、数据含义和性能预算。系统不执行模型推理，也不生成替代真实观测的评分。


## 重点区域建筑接入
区域页增加北京 CBD、上海陆家嘴、成都金融城入口。当前公开 OSM 服务访问失败，尚未打包真实建筑数据，入口显示“待数据”。图层页可输入自有 3D Tiles 的 tileset.json 地址，加载后定位，支持建筑显示开关。模型服务需允许跨域访问；本地可把完整模型目录放入 frontend/public/models，地址填写 /models/目录/tileset.json。
区域轮廓数据放在 frontend/public/buildings/{id}.geojson，并更新 areas.json 的 available 为 true。GeoJSON Polygon 属性 height 单位米，heightSource 记录高度来源；无高度默认 12m 示意。此类轮廓拉伸不等同于带纹理倾斜摄影实景模型。


## 城市高清影像与带纹理实景（更新）
默认底图改为 ArcGIS World Imagery，具体清晰度取决于地区覆盖；不可用时自动回退 Sentinel-2，再回退离线底图。区域页新增“县城社区”“寺庙景区”两个 Mars3D 官方公开倾斜摄影示例，按数据原始地理位置显示，不是北京、上海或成都建筑数据。点击示例自动隐藏气象色斑，方便观察建筑纹理；可在图层页重新打开气象场。
图层页支持建筑显示开关、模型高程偏移（米）和自有 tileset.json 地址。数据按视角流式加载，不把城市模型整包下载到项目。公开演示服务受网络、覆盖与提供方使用条件限制。
开发环境由 Vite 提供 /scene-assets/ 固定源转发；生产环境应将 /scene-assets/ 转发到 FastAPI，与 /api/ 类似，后端已注册该路由。只允许固定影像和两个示例路径，不转发账号凭据。保留影像来源与版权信息。
数据来源：https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer ，https://mars3d.cn/docs/basis/tileset/ ，https://mars3d.cn/docs/basis/ 。


## 加载状态与性能优化
地形高程默认启用；连接或瓦片失败会显示真实状态及重试入口，不把开关状态当作加载成功。默认“均衡”显示质量，可切换“流畅/精细”；地形与影像、模型按当前视角渐进加载。
待加载计数合并地球瓦片与模型瓦片；单次持续加载超过 20 秒或出现失败后，提示资源超时/失败，已加载内容仍可操作，并提供“重试资源”。不会一直用“细化中”代表失败。外部源实际缺失的瓦片不能通过前端补出。
区域列表对尚无数据的重点区域禁用按钮，显示待数据。模型支持定位、卸载、高程偏移与显示开关；在模型视角下，俯视和倾斜围绕该模型，选省份或复位后恢复区域视角。
