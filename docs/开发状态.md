# 开发状态

## 当前阶段

阶段十一“检验看板”已经完成第一轮。系统将阶段十保存的真实检验结果展示为总体指标、分级检验、逐时效曲线和分时段统计；没有真实检验任务时只显示空状态，不填充演示评分。

根据当前演示范围，已移除顶部“风险预警”独立页面入口；首页风险摘要及后端风险记录暂时保留，不影响预测结果联动和历史数据兼容。

检验评估页已参考AIM-FDP确定性预报页面重新设计：采用顶部条件筛选、单一主指标逐时效曲线、总体指标摘要、分级降水表格、数据追溯和折叠式模型对比的层级结构，避免把所有指标与图表同时堆叠。当前支持TS、POD、FAR、BIAS、MAE、RMSE、CORR切换，以及全部时效、1—3天、4—10天、11—15天范围切换。

阶段十三第一批“基础动画框架”已完成：主页增加低频深蓝渐变呼吸、低透明度经纬网格、少量蓝色光点、面板边框流光、页面淡入切换和真实加载状态反馈。所有装饰层均禁用鼠标事件，并通过 `prefers-reduced-motion` 在用户开启减少动态效果时自动关闭。

## 当前限制

- GFS当前不参与前端演示主线，底层适配代码与已下载文件保留备用；
- 预测工作台中的SimVP序列仍为明确标识的演示数据；检验看板只接受配对NetCDF的真实计算结果；
- 原AIC项目没有提供SimVP训练权重，真实模型状态为不可用；
- 当前风险阈值为演示规则，不是正式气象预警标准；
- 风险区域坐标由演示网格估算；
- GFS目前下载中国区域，满足当前任务的全国展示；正式竞赛全球规定场仍需后续扩展；
- 尚未接入与预测时次匹配的实况文件，因此检验指标仍不可作为真实评分；
- 已完成省—市名称级联，并为AIC的342项城市代码补齐行政区中心坐标；
- 选择城市后，首页地图自动缩放到城市、显示定位标记，并读取距离该城市中心最近的预测网格曲线；
- 雷达监测调整为后续可选增强项。
