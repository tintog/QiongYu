# 预测业务闭环说明

## 当前可用流程

```text
选择系统演示数据或已上传文件
        ↓
选择 SimVP 模型记录
        ↓
选择未来10帧或20帧
        ↓
创建预测任务
        ↓
生成输入序列和未来预测序列
        ↓
结果写入本地JSON文件
        ↓
任务和摘要写入SQLite
        ↓
前端播放预测帧并查询历史任务
```

## 演示模式与真实模式

- `demo`：生成结构稳定、可重复展示的演示降水序列，用于系统联调和离线竞赛演示。
- `real`：预留给加载可信训练权重后的真实模型推理。
- 当前 SimVP 数据库状态为 `unavailable`。真实模式会被后端拒绝，避免把随机权重输出宣传成真实预报。

## 支持的序列长度

- 输入：5帧。
- 输出：10帧或20帧。
- 演示时间分辨率：6分钟一帧。
- 演示网格：14×14。

## 接口

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| `GET` | `/api/models` | 查询模型及权重状态 |
| `POST` | `/api/prediction/tasks` | 创建并运行预测任务 |
| `GET` | `/api/prediction/tasks` | 查询历史预测任务 |
| `GET` | `/api/prediction/tasks/{task_id}` | 查看任务和完整预测结果 |

## 结果保存

- 任务记录：`prediction_tasks`。
- 统计摘要：`prediction_results`。
- 完整预测帧：`storage/predictions/{task_id}.json`。

演示预测不代表真实天气预报，页面和接口结果中均保留演示数据说明。
