# SQLite 数据库与文件存储设计

## 存储原则

- SQLite 保存文件信息、模型信息、预测任务、预测摘要和风险预警。
- NPY、NetCDF、雷达基数据、模型权重和结果图片保存在 `storage` 目录。
- 数据库仅记录相对路径，不把大型二进制文件写入数据表。
- 后端启动时自动创建目录、数据库和数据表。

## 数据库位置

```text
storage/database/qiongyu.db
```

## 数据表

| 表名 | 用途 | 当前阶段 |
| --- | --- | --- |
| `data_files` | 文件名称、路径、哈希、大小、来源和处理状态 | 已启用 |
| `models` | 模型名称、版本、框架、权重路径和可用状态 | 已启用 |
| `prediction_tasks` | 预测参数、状态、运行时间和错误信息 | 阶段三使用 |
| `prediction_results` | 预测统计摘要和结果文件路径 | 阶段三使用 |
| `risk_warnings` | 风险区域、等级、阈值、数值和建议 | 阶段四使用 |

## 文件目录

```text
storage/
├── uploads/       普通上传数据
├── datasets/      系统演示数据
├── radar/         雷达基数据和雷达图
├── predictions/   模型预测结果
├── models/        模型权重
├── exports/       导出文件
└── database/      SQLite数据库
```

## 文件管理接口

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| `GET` | `/api/storage/status` | 查看数据库、目录和各表记录数量 |
| `GET` | `/api/data/files` | 查询文件记录 |
| `GET` | `/api/data/files/{file_id}` | 查看单个文件记录 |
| `POST` | `/api/data/files` | 上传文件并写入数据库 |

支持的扩展名为 `.npy`、`.nc`、`.nc4`、`.cdf`、`.bin`、`.bz2`、`.gz`、`.json` 和 `.csv`，单文件限制为100MB。

## 模型状态

数据库初始化时会登记 SimVP 模型，但其状态为 `unavailable`，原因是原AIC代码包没有提供训练权重。在接入可信权重前，系统不能将其标识为真实可用模型。
