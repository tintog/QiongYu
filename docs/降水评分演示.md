# 降水评分演示

选择0928预报，在检验看板选择“0928模拟降水实况 · 6小时累计”、6小时累计降水，再点击“开始检验”。

模拟参考由0928确定性预报进行一格纬度、两格经度位移、强度调整和固定随机种子的扰动生成。它依赖被检验的预报，不是独立观测，也不能证明模型精度。文件、批次及检验页均保留模拟标记。

阈值为0.1、1、5、10、20 mm/6h，达到阈值记为降水事件。H为命中、F为空报、M为漏报：TS=H/(H+F+M)，POD=H/(H+M)，FAR=F/(H+F)，BIAS=(H+F)/(H+M)。分母为零显示空值。全部或分时段评分先合并列联表计数，再计算比例，不平均各时效评分。

真实参考接入格式：变量TP(time,lat,lon)，单位mm、mm/6h或m，单文件一个UTC有效时间，升序0.25°中国区域网格，与预报坐标严格匹配。文件名OBS_ANALYSIS_YYYYMMDDHH.nc。全局属性product_type=observation、time_zone=UTC、source=真实来源；accumulation_start、accumulation_end使用UTC ISO时间，end等于time，起止相差6小时。模拟文件使用product_type=simulated。尚不支持24小时累计参考或自动重网格。

通过数据管理导入真实参考批次后，在检验看板选择它即可使用相同评分流程；不要把模拟批次改名作为真实观测。
