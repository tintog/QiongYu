# 风险预警闭环说明

## 功能定位

本系统生成的是“基于预测降水阈值的风险提示”，用于竞赛演示和辅助理解预测结果，不作为气象主管机构发布的正式气象预警。

任务文档要求根据预测降水阈值生成风险提示，但没有给出正式业务阈值，因此系统当前采用可配置的演示规则。

## 当前演示规则

| 预测网格最大降水 | 风险等级 | 颜色 |
| --- | --- | --- |
| ≥ 50 mm/6h | 高风险 | 红色 |
| ≥ 25 mm/6h | 较高风险 | 橙色 |
| ≥ 10 mm/6h | 关注 | 黄色 |
| < 10 mm/6h | 不生成风险记录 | — |

计算方式：取一次预测任务全部未来帧、全部网格中的最大降水值，与阈值从高到低比较。

## 业务流程

```text
预测任务完成 → 寻找峰值与时刻 → 判定风险等级 → 估算影响区域 → 写入数据库 → 地图和预警中心展示
```

## 接口

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| `GET` | `/api/warnings/rules` | 查询阈值、公式、单位和免责声明 |
| `GET` | `/api/warnings` | 查询历史风险提示 |
| `GET` | `/api/warnings/{warning_id}` | 查询单条风险提示 |
| `POST` | `/api/warnings/generate/{task_id}` | 为已有预测任务生成风险提示 |

新建预测任务完成后，后端会自动执行风险判定。每条记录保存关联任务、风险区域及坐标、等级、预测值、阈值、影响时段、提示文字与建议。
