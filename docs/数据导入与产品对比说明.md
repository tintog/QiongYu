# 数据导入说明

## 运行与入口

修改后需重启后端并刷新前端。通过start.bat运行时前端直接加载源码，无须手动复制构建文件。

导航保留“数据管理”；产品对比页面、列表对比按钮及三个对比接口已移除。本系统读取已生成的预报，不执行模型推理。

## 导入流程

1. 先多选同一批次的NetCDF文件。文件名预选DF／ens／obs类别，可核对类别后上传；最终以文件内部结构校验为准。地面、高空参考文件分批上传。
2. 点击“上传并自动识别”。文件保存到待确认任务，不要求事先填写名称，不会直接入库或替换正在使用的数据。
3. 预览自动识别的产品、版本、参考性质、时间、要素、网格和处理记录。系统读取文件属性，而不是依据所在文件夹推断来源。
4. 确认或修改建议名称、产品、机构、来源说明和版本，可选填标签、备注。未知机构保留“未核实”；名称和机构声明不代表系统认证来源。
5. 同内容完整或部分重复会展示已有批次编号、名称和重复文件数；确需单独登记时明确勾选确认。点击“确认信息并入库”，整批校验通过才进入可用列表。
6. 预报点击“启用预报”，参考批次点击“设为默认参考”。也可在检验看板选择参考批次，不会自动替换当前数据。

名称示例：CRALand · 地面分析 · 20260928；ART_ATM · 高空分析及气压 · 20260928。跨日期会生成起止日期名称。版本从文件属性或原始文件名识别；找不到则标“未声明”，机构不从产品名称推断。

列表可按类别、产品、来源、要素、状态和UTC日期筛选，并搜索名称、唯一编号和标签。预报日期为起报日期，参考场日期为有效时间范围。旧清单兼容读取，不重命名旧批次、不改写旧启用选择。检验看板预先筛选时间、共同要素和网格匹配的参考批次，标出匹配时效数量，列出被排除批次及原因；计算时再次检查共同有效格点。

类型选择是分类登记与结构校验，不是文件转换。DF不含集合member维度，ens需包含多个member；不符合所选结构的文件会被拒绝。不能通过改类型把确定性文件变为集合，更不能把预报变成实况。

下方表格的名称、来源、版本由识别建议及用户确认信息组成；时间、要素、参考性质、网格、成员数和文件数以文件为准。无需手工创建表格或将上传文件移动到data/DF、data/ens目录。

例如导入现有确定性产品：选DF，多选data/DF/20260928中的120个.nc文件，填写批次信息，上传、确认校验并入库、启用。导入集合产品时选ens，使用data/ens/20260928中的文件。不要把不同日期或DF与ens混为一批。

容量限制：每批1—240个文件，单文件128MiB，单批2GiB。仅接收NetCDF文件，不解压ZIP，不接受客户端目录路径。同名文件不覆盖，导入中断后可查看待处理报告并新建任务重试；第一版不支持断点续传。

### 第一版支持格式

- 文件名沿用交付格式，例如`AIMB_V3.3_GLB_SURFACE_OP25_6HOR_FCST_2026092800_006.nc`，包含SURFACE或PLEVELS、唯一YYYYMMDDHH起报时间以及三位预报时效。
- 起报时间按UTC识别；页面有效时间按北京时间显示。time、dtime、init_time和lead_hours必须一致。
- 逐6小时时效，范围+6至+360h；每个已导入时效需同时具备SURFACE与PLEVELS文件。
- 一维lon/lat规则0.25°坐标，覆盖70—140°E、12—56°N，可为全球范围。每个文件仅一组time和dtime。
- 确定性维度顺序为time/dtime/lat/lon；集合为member/time/dtime/lat/lon，成员编号唯一，2—64个成员，同批保持一致。
- 确定性地面变量为TP/T2M/U10/V10/Q2M/MSL；高空为Z500/Q700/T850/U850/V850。集合地面为TP，高空为Z500。
- 温度为degC，风为m/s，位势高度为gpm或米，比湿按文件单位换算，气压Pa或hPa均可。TP必须为mm且明确声明为6小时累计，而非自起报累计。
- 非有限值、负降水、单位不支持、结构错误或批次混杂均阻止入库。其他格式需另做适配，不能直接改扩展名导入。

不足完整15天的批次会列出缺失时效；只有从+6h连续覆盖至至少+24h的批次可以全局启用。其他结构合格的稀疏批次可保存并查看详情，但不可全局启用。缺少完整四段时，不输出标为24小时的累计结果。

上传文件与清单保存于项目根目录`managed_data/batches/<任务编号>/`，启用选择保存在`managed_data/active.json`。原data目录不覆盖。启用选择在重启后保留。移除只改变批次状态、保留上传文件；不能移除正在启用的批次，也不能在页面移除内置数据。第一版没有页面恢复按钮，需要恢复时保留目录和清单，不能直接删除它们。

## 分析参考场接入与检验

本次输出目录为D:\\aaa研究生\\竞赛\\数据\\nc_output\\20260928，内有CRALand和ART_ATM两个子目录，各4个OBS_ANALYSIS_YYYYMMDDHH.nc文件。实际CRALand原始目录少一层日期，为数据/CRALand/20260928。

选择obs，分别上传两类目录的4个文件，填写真实分析来源；确认校验并入库后可点击“设为参考”。打开检验看板，选择预报批次、参考批次、参考批次具备的要素，点击“计算检验”。当前参考类型明确标注为analysis，来源不代表独立认证。不能冒充站点观测。

格式为每文件单一UTC有效时间、time/lat/lon维度、升序0.25°网格，文件声明product_type=analysis、time_zone=UTC。支持气温、比湿、海平面气压、位势高度、10米及850hPa风速；温度K转℃，比湿kg/kg转g/kg，气压Pa转hPa。CRA偏移网格已插值对齐；缺测只按共同有效格点计算。统计为中国区域逐格点等权，不代表竞赛官方评分。

预报2026092800可匹配+6、+12、+18h；2026092700可匹配+24、+30、+36、+42h。没有9月29日实况，不计算9月28日起报的+24h。匹配网格不一致时拒绝，不使用近邻时刻替代。

这两类文件不含降水，故本版obs导入不支持降水检验，不生成TS/POD/FAR。初始场也不等于未来时刻实况。

## 验证与限制

后端测试：在backend目录运行`.venv\Scripts\python.exe -m unittest discover -s tests -v`。覆盖单位、联动、导入校验、批次启用、原有内部计算回归、对比接口404及分析场导入、单位换算、实际HTTP检验；上传、启用和清理由隔离临时存储承担，不修改交付数据与用户启用选择。

前端组件测试：在frontend目录运行`node tests/data-workflow.mjs`和`node tests/point-linkage.mjs`。使用真实Vue组件setup逻辑和模拟接口，检查导入进度、确认入库、启用事件、对比入口移除、参考场类型选择和单点联动，不代表真实浏览器画布已经验收。

前端生产构建保留既有大包体积警告。此前浏览器控制工具启动时因Windows沙箱deny-read ACL错误失败，重试后仍失败，因此未完成真实浏览器点击、截图及视觉验收。实际录制视频前仍需人工检查地图、曲线、上传控件和窄屏布局。

服务按现有启动脚本仅监听127.0.0.1；新增写入接口拒绝非允许本地页面来源的跨站请求。本版本面向本地演示，不具备公开部署所需的账号、权限、存储配额和多用户隔离。
