# 登录与角色管理

系统入口已启用登录页，可选择普通用户或管理员。角色选择必须与账户实际角色一致。

本地演示初始账户：普通用户 `user` / `User@2026`；管理员 `admin` / `Admin@2026`。
首次创建账户数据库前，可用环境变量 `QIONGYU_ADMIN_PASSWORD`、`QIONGYU_USER_PASSWORD` 设置初始密码。数据库存在后不会重置账户。

普通用户可浏览预报产品、开展检验、上传个人数据、填写元数据并提交审核。只能访问自己的上传任务。
管理员可管理全部任务，审核入库、退回修改、启用产品、设定默认参考、移除非启用批次，以及管理账户和查看操作日志。
现有校验可用批次作为已开放产品保留；普通用户不能切换全局启用批次。全局切换会影响所有用户，管理员应在需要时执行。

上传后提交审核不会自动入库。管理员在任务列表选择“查看／确认”，检查文件报告和来源说明，选择审核通过或填写原因退回。退回后用户可修改并重新提交。审核通过不代表来源得到独立认证。

账户和日志保存在 `managed_data/auth/accounts.sqlite3`；密码使用带随机盐的PBKDF2摘要存储。登录使用HttpOnly Cookie，8小时过期；退出、停用或修改账户会使对应会话失效。
最后一个有效管理员不能停用或降级。管理员应通过用户管理设置自己的新密码。

当前实现不包含自助注册、密码找回邮件、个人独立预报批次切换、风险规则编辑和批次停用；这些功能需要单独扩展。当前风险提示规则仍沿用原有演示口径。

启动方式保持不变：运行 `start.bat`，访问 http://127.0.0.1:5173 。
权限测试：进入backend目录，安装requirements-dev.txt，运行 `python -m unittest discover -s tests -p test_auth_roles.py -v`。
